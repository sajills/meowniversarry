# 𝓜𝓮𝓸𝔀𝓷𝓲𝓿𝓮𝓻𝓼𝓪𝓻𝔂

***A tiny anniversary website for my girlfriend, because saying "love you" once apparently wasn't going to cut it.***

First come the notifications. Then a chat. Then an envelope, a letter, falling petals and a soundtrack. I built an entire side quest just to say "I love you." Efficient? No. Worth it? Obviously.

## 𝓜𝓪𝓭𝓮 𝓕𝓸𝓻 𝓨𝓸𝓾𝓻 𝓟𝓱𝓸𝓷𝓮

It is phone-first: portrait layout, touch-friendly bits, spacing sized for a mobile screen. You have your phone on you anyway, so I'm calling this a feature and not a limitation.

## 𝓣𝓱𝓮 𝓜𝓾𝓼𝓲𝓬 𝓢𝓲𝓽𝓾𝓪𝓽𝓲𝓸𝓷

| Question | Answer |
| :--- | :--- |
| When does the song start? | Right after the date finishes typing. |
| What if it stays silent? | Your browser is being dramatic. Tap anywhere once and it plays. |
| Why do I have to tap? | Browsers refuse to play sound until you touch the page. I did not make this rule, I just suffer under it. |

## 𝓡𝓾𝓷 𝓘𝓽 𝓨𝓸𝓾𝓻𝓼𝓮𝓵𝓯

You don't need to. The live link above does everything. But if you insist on doing it the hard way:

| Step | What to do |
| :--- | :--- |
| 1 | Install Node.js. Yes, really. |
| 2 | Open a terminal in the project folder and run `node serve.js`. |
| 3 | Visit `http://localhost:8000`. |

Do not just double-click `index.html`. Browsers tend to block the MP3 when you open it that way, and then the song is gone and so is the mood.

## 𝓣𝓱𝓮 𝓕𝓲𝓵𝓮𝓼, 𝓔𝓱

| File | What it does |
| :--- | :--- |
| `index.html` | The page structure. The stage is set. |
| `style.css` | Layout, look and animations. Very important for the emotional impact. |
| `script.js` | Notification timing, chat, envelope and letter. The brains of the operation. |
| `serve.js` | A tiny local server so the music is allowed to exist. |
| `photos/` | The pictures: the envelope, the chat avatar and two backgrounds. |
| `audio/everything.mp3` | The soundtrack, cued after the date appears. Main character moment. |

## 𝓕𝓸𝓷𝓽𝓼

System fonts keep things fast and readable. Want to get fancy? Palatino or Georgia for the letter, and Avenir Next, SF Pro Display or Helvetica Neue for the interface. Cursive is already doing its thing on the letter, so please don't overdo it.
